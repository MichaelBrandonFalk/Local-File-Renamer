Local File Renamer

Scan a Mac folder into a CSV rename plan, fill in desired names, then run the plan against real local files with a confirmation step.

Download v1.0 for Apple Silicon

Compatibility

  • Self-contained app bundle: no Python, Homebrew, Tkinter, or command-line tools required.
  • Built for Apple Silicon Macs with macOS 11 Big Sur or newer.
  • Includes its own Python 3.13 and Tcl/Tk runtime libraries.

Workflow

  • Choose a local folder and write a CSV with each current file name.
  • Edit the desired_name column or add one rename row in the app.
  • Click Run Renames and confirm before files are changed.
  • Review the status column after the run finishes.

CSV Columns

  • folder_location: folder containing the file.
  • current_name: existing file name.
  • desired_name: new file name.
  • status: result written by the app.
