A few practical details

How do I open the download?

Windows: open the downloaded .exe. Linux Mint: install the .deb, then open Local File Renamer from the applications menu. For the portable Linux archive, extract it and run local-file-renamer. Mac: extract the ZIP and open the app. See the release notes for platform-specific startup guidance.

Do I need to install anything else?

No Python, spreadsheet application, or developer tools are needed to run the app. The runtime is bundled. Manual CSV and Excel plans work offline; NEB artwork preparation uses an internet connection to verify the current default rules. Files are processed locally.

Will it change my original files?

Manual rename plans can rename originals in place. Select Rename copies to keep them untouched and choose an output folder. NEB artwork deliveries always copy required matches into a new delivery location, leaving source files unchanged.
