Local File Renamer

Scan a Mac folder, export a CSV or spreadsheet rename plan, load the edited plan, then rename local files with a confirmation step.

Compatibility

  • Self-contained app bundle: no Python, Homebrew, Tkinter, or command-line tools required.
  • Built for Apple Silicon Macs with macOS 11 Big Sur or newer.
  • Includes its own Python 3.13 and Tcl/Tk runtime libraries.

Workflow

  • Choose a local folder and export a rename plan as CSV or `.xlsx`.
  • Edit the desired_name column in your preferred spreadsheet tool.
  • Browse to the edited plan, load it, then click Run Renames.
  • Review the status column after the run finishes.

Plan Columns

  • folder_location: folder containing the file.
  • current_name: existing file name.
  • desired_name: new file name.
  • status: result written by the app.
